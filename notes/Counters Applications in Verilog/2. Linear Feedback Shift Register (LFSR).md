A **linear feedback shift register (LFSR)** is a shift register whose input bit is a linear function of some of its previous state bits. It’s one of the cheapest ways to generate long pseudo-random bit sequences in hardware.

![[lfsr.png | center]]

The following module represent the `linear feedback shift register`.
```verilog
module lfsr
	#(parameter N = 3)
	(
		input clk,
		input reset,
		output [1:N] Q
	);
	
	reg [1:N] Q_reg, Q_next;
	wire taps;
	
	always @(posedge clk, posedge reset)
	begin
		if (reset)
			Q_reg <= 'd1; // LSFR shouldn't start with 0 or FFFF
		else
			Q_reg <= Q_next;
	end
	
	// Next state logic
	always @(taps, Q_reg)
		Q_next = {taps, Q_reg[1:N-1]};
		
	// Output logic
	assign Q = Q_reg;
	
	// N = 3
	assign taps = Q_reg[3] ^ Q_reg[2];
	

endmodule
```
