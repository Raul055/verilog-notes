**PWM (Pulse Width Modulation)** is a way of controlling how much power a device gets by switching a digital pin rapidly between HIGH and LOW, instead of using a true analog voltage.

# Main Characteristics
## Duty Cycle
The **duty cycle** is the percentage of each cycle the signal spends HIGH.

![[duty-cycle-1.png | center]]

The *duty cycle* can be modified according to the percentage needed.

![[duty-cycle-2.png]]

We care about the *duty cycle* because of the **average voltage** the PWM generates. If we connect an analog device, the PWM signal will be read (according to the *duty cycle*) as the **average voltage** generated over time. The way we can compute the **average voltage** that can be read is borrowed the same way we can obtain *expectation* from probability. It follows the expression.
$$ E[X] = \textmu_{X} = \sum_{i} x_{i} P_(x_{i}) $$
where $x_{i}$ is each possible outcome and $P(x_{i})$ is its probability. From this expression, considering $V$ as voltage, we can define the *expected voltage* as:
$$ E[V] = \textmu_{V} = \sum_{i} v_{i}P(v_{i}) $$
The instant $t$ is uniformly distributed over $[0,T]$, so: 
$$f(t)=\frac{1}{T}$$
We know that $V$ can only take two values (this being a digital signal), which are $V = V_{cc}$ and $V = 0$. Also, $V=V_{cc}$ when $0 \leq t \leq t_{on}$, so:
$$ P(V_{cc}) = \frac{t_{on}}{t_{PWM}}$$
With the definition of *duty cycle*:
$$ P(V_{cc}) = \frac{t_{on}}{t_{PWM}} = d$$
So, because the sum of all probabilities is 1, we can obtain $P(0)$:
$$1 = P(V_{cc}) + P(0)$$
$$P(0) = 1 - P(V_{cc}) = 1 - d $$
Going back to the *expected voltage* expression:
$$ E[X] = \textmu_{X} = \sum_{i} x_{i} P_(x_{i})=0(P(0)) + V_{cc}(P(V_{cc})) $$
$$ E[X] = 0(1-d) + V_{cc}(d)$$
$$ E[X] = d(V_{cc}) $$

## Resolution
The **resolution** is the minimum incremental step (granularity) of the duty cycle. It is specified by the number of bits **R** (minimum step $\frac{1}{2^R}$).

**Example**
$R = 8$ bits, the minimum incremental step is $\frac{1}{256}$, so the duty cycles are:
$$ \frac{0}{256}, \frac{1}{256}, \frac{2}{256}, ..., \frac{255}{256}, \frac{256}{256}$$
