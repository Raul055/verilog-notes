## Reset
Consider the following module.
```verilog
module D_FF_reset
	(
		input clk,
		input D,
		input reset, // asynchronous
		input clear_n, // synchronous
		output Q
	);
	
	reg Q_reg, Q_next;
	
	// Flip-Flop
	always @(negedge clk, negedge reset_n)
	begin
		Q_reg <= Q_reg;
		// Asynchronous reset
		if (!reset_n)
			Q_reg <= 1'b0;
		else
			Q_reg <= Q_next;
	end
	
	// Next state logic
	always @(D, clear_n)
	begin
		Q_next = Q_reg;
		// Synchronous reset
		if (!clear_n)
			Q_next = 1'b0;
		else:
			Q_next = D;
	end
	
	assign Q = Q_reg;

endmodule
```
- **Asynchronous *reset***: it reset the moment *reset* is done (in module, when a `negedge` of reset signal is made).
- **Synchronous *reset***: it waits the next *clock cycle* for the reset to be done.

## Set & Reset
Given this D FF.

![[D_FF_reset.png | center]]

It can be modeled like this:
```verilog
module D_FF_set_reset
	(
		input clk,
		input D,
		input reset_n,
		input set_n,
		output Q
	);
	
	reg Q_reg, Q_next;
	
	// Flip-Flop
	always @(negedge clk, negedge reset_n)
	begin
		Q_reg <= Q_reg;
		// Asynchronous RESET
		if (!reset_n)
			Q_reg <= 1'b0;
		else
			Q_reg <= Q_next;
	end
	
	// Next state logic
	always @(D, set_n)
	begin
		Q_next = Q_reg;
		// Synchronous SET
		if (!set_n)
			Q_next = 1'b1;
		else:
			Q_next = D;
	end
	
	assign Q = Q_reg;

endmodule
```
