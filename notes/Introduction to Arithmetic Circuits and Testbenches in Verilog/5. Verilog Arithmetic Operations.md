The following correspond to several **arithmetic operations** in verilog.

![[arithmetic-operations.png | center]]

For example, consider the following module as a base.
```verilog
module arithmetic_operators
	#(parameter N=4)
	(
		input [N-1:0] x,
		input [N-1:0] y,
		output [N-1:0] s,
		output c_out, overflow
	);

	// sum
	assign s = x + y;

endmodule
```
The last module just assigns `s` to the sum of `x` and `y`. If we want the *carry_out* (`c_out`), we can implement it. Instead of a simple sum like this:
```verilog
// sum
assign s = x + y;
```

We can implement it like this:

```verilog
wire [N:0] sum; // (n + 1) bits
assign sum = {1'b0, x} + {1'b0, y}; // MSB to 0 and passed to (n+1) bits
assign s = sum[N-1:0]; // all bits but MSB from sum correspond to the solution
assign c_out = sum[n]; // MSB of sum is c_out
```
Basically, we expanded the expression to have `N+1` bits to consider the `c_out`bit. Nevertheless, the concatenation of `0` and `x` & `y` is not really necessary, as verilog automatically expands to the maximum length of the vector, and since `sum` was already defined as `N+1` bits, `x` & `y` were also expanded  to `N+1` bits by default. So the following, in this case, is equivalent. 
```verilog
wire [N:0] sum; // N+1 bits
assign sum = x + y; // by default, N+1 bits
assign s = sum[N-1:0]; // all bits but MSB from sum correspond to the solution
assign c_out = sum[n]; // MSB of sum is c_out
```
	Note: carefull with this default behaviour when dealing with arithmetic operations.
Additionally, the upper expressions can also be defined as the following.
```verilog
assign {c_out, s} = x + y; // expanded to N+1 bits & and assigned c_out and s
```
And if we want to implement the **overflow** (`overflow`), we can do something like this.
```verilog
assign {c_out, s} = x + y; // expanded to N+1 bits & and assigned c_out and s
assign overflow = (x[N-1] & y[N-1] & ~s[N-1]) | (~x[N-1] & ~y[N-1] & s[N-1]); // overflow
```
The **overflow** flag is launched when:
> The *MSB* of `x` and `y` are `1` and `s` is `0` (*two negative numbers were added and the sum was positive*) **OR** the *MSB* of `x` and `y` are `0` and `s` is `1` (*two positive numbers were added and the sum was negative*).
