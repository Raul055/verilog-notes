# 2's Complement
In an `N-bit number`, the most significant bit (MSB) carries a negative weight of `-2^(N-1)`, and all the other bits carry their usual positive weights. To obtain the *2's Complement* of a number, first you invert (negate ~) all bits and then add `1`. For example:

![[2-complement.png | center]]

This is usefull because subtraction is the negated operand of addition.
$$ A - B = A + (\textasciitilde B) + 1$$

# Adder/Substractor
Due to the `2's Complement` we can integrate and adder and a substractor like as it follows.

![[adder-substractor.png | center]]

In here the `Add/Substract control` signal determines if it is acting as an adder (`control = 0`) or as a substractor (`control = 1`). When acting as an adder, the XOR gates function as buffers an all `y` is passed to the `n-bit adder`. However, when acting as a substractor, the XOR gates function as a **1's complement** of `y`, and then $c_0$ is added (which is 1), so at the end, we obtained the **2's complement** that is being added to the `n-bit adder`.

The following module represent a `4-bit` **adder/substractor** and utilizes the `rca_4bit` adder from [[1. Adders]].

```verilog
module adder_substractor_4bits
	(
		input [3:0] x, y,
		input add_n,
		output [3:0] s,
		output c_out
	);
	
	// xor_y
	wire [3:0] xor_y;
	assign xor_y[0] = y[0] ^ add_n;
	assign xor_y[1] = y[1] ^ add_n;
	assign xor_y[2] = y[2] ^ add_n;
	assign xor_y[3] = y[3] ^ add_n;
	
	// rca
	rca_4bit A0 (
		.x(x),
		.y(y),
		.c_in(add_n),
		.s(s),
		.c_out(c_out)
	);
	
	
endmodule
```

Or better, the parametrized, `N-Bit` **adder/substractor** with the `rca_nbit` module form [[2. Generic Verilog Code Parametrization]].

```verilog
module adder_substractor_nbits
	#(parameter N=4)
	(
		input [N-1:0] x, y,
		input add_n,
		output [N-1:0] s,
		output c_out
	);
	
	// xor_y
	wire [N-1:0] xor_y;
	
	// generate xor gates
	generate
		genvar k;
		for(k = 0; k < N; k = k + 1)
		begin: bits
			assign xor_y[k] = y[k] ^ add_n;
		end
	endgenerate
	
	// rca
	rca_nbit #(.N(N)) A0 (
		.x(x),
		.y(y),
		.c_in(add_n),
		.s(s),
		.c_out(c_out)
	);
	
endmodule
```
