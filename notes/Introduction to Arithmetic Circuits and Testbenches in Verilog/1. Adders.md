# Half Adder
A **half-adder** is a basic combinational logic circuit that adds two single-bit binary inputs, $A$ and $B$, to produce two outputs: a **Sum** and a **Carry**.

![[half-adder.png| center]]

The following module represent a **half-adder**.
```verilog
module half_adder 
	(
		input x, y,
		output c, s
	);
	
	// Sum
	assign s = x ^ y;
	
	// Carry
	assign c = x & y;
	
endmodule
```

# Full-Adder

A **full-adder** is a combinational digital logic circuit that adds three one-bit binary numbers: two operands ($A$ and $B$) and a carry-in bit ($C_{in}$) from a previous stage.  A **full-adder** can be implemented using two half-adders and one OR gate.

![[full-adder.png | center]]

The following module represent a **full-adder** using the **half-adder** module.
```verilog
module full_adder 
	(
		input x, y, c_in
		output s, c_out
	);
	
	// half-adder 0 
	wire c1, s1, c2;
	half adder HA0 (
		.x(x),
		.y(y),
		.c(c1),
		.s(s1)
	);
	
	// half-adder 1
	wire c1, s1;
	half adder HA1 (
		.x(c_in),
		.y(s1),
		.c(c2),
		.s(s)
	);
	
	// carry out
	assign c_out = c1 | c2;
	
endmodule
```

# Ripple-Carry Adder
A **ripple-carry adder (RCA)** is a combinational digital circuit used to add two `n-bit` binary numbers by cascading `n full-adders` in series.  In this architecture, the **carry-out** of each full adder stage serves as the **carry-in** for the next most significant stage, causing the carry signal to "ripple" from the least significant bit to the most significant bit.

![[ripple-carry-adder.png | center]]

The following module represent a `4-bit`**ripple-carry adder** using the **full-adder** module.

```verilog
module rca_4bit
	(
		input [3:0] x, y,
		input c_in,
		output [3:0] s,
		output c_out
	);
	
	wire [3:1] c;
	
	full_adder FA0 (
		.x(x[0]),
		.y(y[0]),
		.c_in(c_in),
		.s(s[0]),
		.c_out(c[1])
	);
	
	full_adder FA1 (
		.x(x[1]),
		.y(y[1]),
		.c_in(c[1]),
		.s(s[1]),
		.c_out(c[2])
	);
	
	full_adder FA2 (
		.x(x[2]),
		.y(y[2]),
		.c_in(c[2]),
		.s(s[2]),
		.c_out(c[3])
	);
	
	full_adder FA3 (
		.x(x[3]),
		.y(y[3]),
		.c_in(c[3]),
		.s(s[3]),
		.c_out(c_out)
	);
	
endmodule
```
