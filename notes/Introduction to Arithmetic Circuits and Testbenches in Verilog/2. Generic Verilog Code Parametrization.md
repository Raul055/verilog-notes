**Generic Verilog Code Parametrization** means to write efficient code by writing generic modules with the use of parameters. For example,  we analyze the `N-Bit Adder`.

![[n-bit-adder.png | center]]

The following module corresponds to an `N-Bit` **adder** using the **full-adder** module from [[1. Adders]].

```verilog
module rca_nbit
	#(parameter N=4)
	(
		input [N-1:0] x, y,
		input c_in,
		output [N-1:0] s,
		output c_out
	);
	
	// for generate block
	wire [N:0] c; // due to c_n, the c has n+1 bits
	assign c[0] = c_in; // first bit as c_in
	assign c_out = c[n]; // c_n is c_out
	
	// generate block
	generate
		// for-loop kinda-like C
		genvar k; // SPECIFICALLY for a generate block
		for (k = 0; k < N; k = k + 1) // cannot use k++ like C
		begin: stage // optional
			full_adder FA (
				.x(x[k]),
				.y(y[k]),
				.c_in(c[k]),
				.s(s[k]),
				.c_out(c[k+1])
			);
		end
	endgenerate

endmodule
```

	The generate block is usually used for replicated hardware structures.

This generic form of writing allows us to use modules in a simple way. For example, the following `multi_adders` module uses the `rca_nbit` module generically.

```verilog
module multi_adders
	(
		// 16-bit adder
		input [15:0] a, b,
		output [15:0] s_ab,
		output c_out_ab,
		
		// 32-bit adder
		input [31:0] x, y,
		output [31:0] s_xy,
		output c_out_xy 
	);
	
	// 16-bit adder
	rca_nbit #(.N(16)) adder_16 (
		.x(a),
		.y(b),
		.c_in(0),
		.s(s_ab),
		.c_out(c_out_ab)
	);
	
	// 32-bit adder
	rca_nbit #(.N(32)) adder_16 (
		.x(x),
		.y(y),
		.c_in(0),
		.s(s_xy),
		.c_out(c_out_xy)
	);
	
endmodule
```
