# Design Steps
The following steps are recommended for the design of a FSM.
1. Draw the state diagram based on specifications & desired behavior.
2. Reduce the number of states if necessary.
3. Assign binary values to states.
4. Obtain the binary-coded state table.
5. Choose FF type.
6. Get simplified FF input equations & output equations.
7. Draw circuit diagram.

# Sequence Detector
A **sequence detector** is an FSM that watches a serial bit stream and asserts an output when a specific pattern appears.
