# Design Steps
The following steps are recommended for the design of a FSM.
1. Draw the state diagram based on specifications & desired behavior.
2. Reduce the number of states if necessary.
3. Assign binary values to states.
4. Obtain the binary-coded state table.
5. Choose FF type.
6. Get simplified FF input equations & output equations.
7. Draw circuit diagram.

# Sequence Detector
A **sequence detector** is an FSM that watches a serial bit stream and asserts an output when a specific pattern appears.

![[sequence-detector.png | center]]

Suppose a *sequence detector* that searches for the pattern `101`. With a *Mealy machine* approach, and, by design, overlapping is okay, we can inferr the following.

![[sequence-detector-mealy.png | center]]

First, we draw the state diagram.

![[sequence-detector-state-diagram-1.png | center]]

In here, we take into account the desired sequence of bits read is `101` for an output of `1`. The thought process of the creation of the FSM is the following.
1. $s_0$ is the initial state, where no bit has been seen (or reset state). If `0` is seen, stay in the current state; else, if a `1` is seen, move to a new state: $s_1$.
2. In $s_1$, if a `1` is seen, stay in the current state. If not, a `0` is seen, and move to a new state: $s_2$.
3. In $s_2$, if a `0` is seen, move to the initial state $s_0$. If not, a `1` is seen and move to $s_2$, and output $y = 1$.
After the *state diagram* was done, we can assign binary values to the states.
