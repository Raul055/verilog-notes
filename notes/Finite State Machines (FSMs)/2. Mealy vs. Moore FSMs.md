# General Synchronous System
We know that a FSM is a **general synchronous system**. It contain a **state register**, which is a register that stores the current state where the FSM is.

![[general-synchronous-sys.png | center]]

The difference between the **Moore** and **Mealy** machine is in the red line of the *general synchronous system* diagram. A *Moore* machine will have it, while a *Mealy* machine won't.

# Mealy Machine
A **Mealy machine** is an FSM whose outputs depend on both the **current state and the current inputs**. A *Mealy machine* is a deterministic finite-state transducer: for each state and input, at most one transition is possible.

We can implement a `001 detector` as a *Mealy machine* with the following module.

```verilog
module mealy_001_detector
	(
		input clk,
		input reset,
		input x,
		output y
	);
	
	reg [1:0] state_reg, state_next;
	
	// State register
	always @(posedge clk, posedge reset)
	begin
		if(reset)
			state_reg <= 'b0;
		else
			state_reg <= state_next;
	end
	
	// Next state logic
	always @(*)
	begin
		state_next[1] = ~state_reg[1] & state_reg[0] & x;
		state_next[0] = (~state_reg[1] & ~x) | (~state_reg[0] & ~x);
	end
	
	// Output logic
	assign y = state_reg[1] & ~state_reg[0] & x;

endmodule
```
