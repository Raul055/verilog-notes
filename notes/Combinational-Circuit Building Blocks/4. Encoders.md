An **encoder** is the inverse of a decoder. It takes $2^n$ input lines  and produces an $n$-bit binary code saying which line is active.

![[encoders.png | center]]

___
# 4x2 Encoder

The `4x2` encoder implements **4** inputs and **2** outputs.

![[4x2-encoder.png | center]]

The following module represent the `4x2 Encoder`.

```verilog
module encoder_4x2
	(
		input [3:0] w,
		output reg [1:0] y
	);
	
	always @(w)
	begin
		y = 2'bx; // default
		case(w)
			4'b0001: y = 2'b00;
			4'b0010: y = 2'b01;
			4'b0100: y = 2'b10;
			4'b1000: y = 2'b11;
			default: y = 2'bxx; 
		endcase
	end
	
endmodule
```

The following is also valid.

```verilog
module encoder_4x2
	(
		input [3:0] w,
		output reg [1:0] y
	);
	
	always @(w)
	begin
		y = 2'bx; // default
		if (W == 4'b0001) y = 2'b00;
		else if (w == 4'b0010) y = 2'b01;
		else if (w == 4'b0100) y = 2'b10;
		else if (w == 4'b1000) y = 2'b11;
		else y = 2'bxx;
	end
	
endmodule
```

# 4x2 Priority Encoder
A **priority encoder** is an encoder that handles multiple active inputs. It outputs the binary code of the highest-priority active input and ignores the rest. It also reports whether any input is active at all.

![[4x2-priority-encoder.png]]

THe following module represent the `4x2 Priority Encoder`.

```verilog
module priority_encoder_4x2
	(
		input [3:0] w,
		output z,
		output reg [1:0] y
	);
	
	assign z = |w;
	
	always @(w)
	begin
		y = 2'bxx;
		if(w[3])
			y = 2'b11;
		else if (w[2])
			y = 2'b10;
		else if (w[1])
			y = 2'b01;
		else if (w[0])
			y = 2'b00;
		else
			y = 2'bxx;
	end

endmodule
```

The following is also valid.

```verilog
module priority_encoder_4x2
	(
		input [3:0] w,
		output z,
		output reg [1:0] y
	);
	
	assign z = |w;
	
	always @(w)
	begin
		y = 2'bxx;
		casex(w)
			4'b1xxx: y = 2'b11;
			4'b01xx: y = 2'b10;
			4'b001x: y = 2'b01;
			4'b0001: y = 2'b00;
			default: y = 2'bxx;
		endcase
	end

endmodule
```
