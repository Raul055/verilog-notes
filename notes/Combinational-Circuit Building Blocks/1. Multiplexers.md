# Multiplexer
A **multiplexer** (**MUX**) is a digital circuit that selects one of several input signals and forwards it to a single output. It works like a rail switch: many lines in, one line out, and a set of **select lines** decides which input gets through.
___
# 2x1 Multiplexer

![[2x1-mux.png | center]]

For example, we can build a `2x1 Mux` with the following module.
```verilog
module mux_2x1
	(
		input w0, w1,
		input s,
		output f
	);
	
	/* is s asserted? if yes return w1, else return w0 */
	assign f = s ? w1 : w0;
	
endmodule
```
Or with an `always` block.
```verilog
module mux_2x1
	(
		input w0, w1,
		input s,
		output reg f // reg because always block
	);
	
	// Will assert if w0, w1 or s changes
	always @(w0, w1, s)
	begin
		f = s ? w1: w0;
	end
	
endmodule
```
Additionally, we can parametrize our module.
```verilog
module mux_2x1_nbits
	#(parameter N=3)
	(
		input [N-1:0] w0, w1,
		input s,
		output reg f // reg because always block
	);
	
	// always block will assert if w0, w1 or s changes
	always @(w0, w1, s)
	begin
		f = s ? w1: w0;
	end
	
endmodule
```

# 4x1 Multiplexer
We can implement a `4x1` multiplexer as the following module.
```verilog
module mux_4x1_nbit
	#(parameter N=3)
	(
		input [N-1:0] w0,l w1, w2, w3,
		input [1:0] s,
		output reg [N-1:0] f
	)
	
	always @(w0, w1, w2, w3, s)
	begin
		f = s[1] ? (s[0] ? w3 : w2) : (s[0] ? w1 : w0);
	end

endmodule
```
We can also describe it with `if else` statements.
```verilog
module mux_4x1_nbit
	#(parameter N=3)
	(
		input [N-1:0] w0,l w1, w2, w3,
		input [1:0] s,
		output reg [N-1:0] f
	)
	
	always @(w0, w1, w2, w3, s)
	begin
		if (s == 2'b00)
			f = w0;
		else if (s == 2'b01)
			f = w1;
		else if (s == 2'b10)
			f = w2;
		else if (s == 2'b11)
			f = w3;
		else
			f = 'bx;
	end

endmodule
```
Another way to do it is with `case` statement.
```verilog
module mux_4x1_nbit
	#(parameter N=3)
	(
		input [N-1:0] w0,l w1, w2, w3,
		input [1:0] s,
		output reg [N-1:0] f
	)
	
	always @(w0, w1, w2, w3, s)
	begin
		case(s)
			2'b00: f = w0;
			2'b01: f = w1;
			2'b10: f = w2;
			2'b11: f = w3;
			default: f = 'bx;
		endcase
	end

endmodule
```

# Generic `1-Bit` Multiplexer
![[1-bit-mux.png | center]]
The following module corresponds to a `1-bit` generic multiplexer.
```verilog
module mux_generic_1bit
	#(parameter IN=5)
	(
		input [IN-1:0] w,
		input [] 
	);
	
endmodule
```
