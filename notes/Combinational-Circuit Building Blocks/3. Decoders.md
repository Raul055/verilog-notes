___
A **decoder** is a combinational circuit that takes an n-bit binary input and activates exactly one of 2ⁿ output lines. It’s the inverse of an encoder: the input is a code, and the output is a one-hot signal saying which code was received.
___
# 2x4 Decoder
A 2x4 decoder has 2 input bits and 4 outputs.

![[2x4-decoder.png | center]]

The following module represent a `2x4 Decoder`.
```verilog
module decoder_2x4
	(
		input [1:0] w,
		output reg [0:3] y
	);
	
	always @(w)
	begin
		y = 4'b0000; // default
		if (w == 2'b00)
			y[0] = 1'b1;
		else if (w == 2'b01)
			y[1] = 1'b1;
		else if (w == 2'b10)
			y[2] = 1'b1;
		else if (w == 2'b11)
			y[3] = 1'b1;
		else
			y = 4'b0000;
	end

endmodule
```

The last module was written as a priority routing network. If prefered, the following module represent the `2x4 Decoder` as a multiplexing network.

```verilog
module decoder_2x4
	(
		input [1:0] w,
		output reg [0:3] y
	);
	
	always @(w)
	begin
		y = 4'b0000; // default
		case(w)
			0: y = 4'b1000;
			1: y = 4'b0100;
			2: y = 4'b0010;
			3: y = 4'b0001;
			default: y = 4'b0000;
		endcase
	end

endmodule
```

An easier way to do it is the following:

```verilog
module decoder_2x4
	(
		input [1:0] w,
		output reg [0:3] y
	);
	
	always @(w)
	begin
		y = 4'b0000; // default
		y[w] = 1'b1;
	end

endmodule
```

# 2x4 Decoder with Enable
We can implement an `enable` signal to the previous decoder.

![[2x4-decoder-enable.png | center]]

The following module represent the `2x4 Decoder with Enable`.
```verilog
module decoder_2x4_en
	(
		input enable,
		input [1:0] w,
		output reg [0:3] y
	);
	
	always @(w, en)
	begin
		y = 4'b0000; // default
		if (enable)
			y[w] = 1'b1;
		else
			y = 4'b0000;
	end

endmodule
```

# Generic Decoder
We can implement a generic decoder that can take $n$ inputs and give $2^n$ outputs.

![[generic-decoder.png | center]]

The following module represent the `generic decoder`.

```verilog
module decoder_generic
	#(parameter N=4) // n inputs
	(
		input [N-1:0] w,
		input en,
		output [0:2**N-1] y // 2^N outputs
	);
	
	
	
endmodule
```
