# T Flip-Flops
A **T flip-flop** (toggle flip-flop) changes state on a clock edge when its input **T** is 1, and holds its state when `T = 0`. It is usually built from a D flip-flop plus an XOR gate.

![[T-Flip-Flops.png| center]]

The following module represent a **T Flip-Flop**.

```verilog
module T_FF
	(
		input clk,
		input T,
		input reset,
		output Q
	);
	
	localparam C2Q_DELAY = 2; // For simulation only
	
	reg Q_reg;
	reg Q_next;
	// Register
	always @(posedge clk, negedge reset)
	begin
		if(reset)
			Q_reg <= 1'b0;
		else
			#C2Q_DELAY Q_reg <= Q_next;
	end
	
	// Next state logic
	assign Q_next = T ? ~Q_reg: Q_reg;
	
	// Output logic
	assign Q = Q_reg;
	
endmodule
```

# Asynchronous Counters
A counter made out of **T Flip-Flops** where only the first stage recieves the `clk` signal. Basically, the T Flip-Flops are cascaded to build the counter. It can be seen as the following `4-bit` counter.

![[asynchronous-counter.png | center]]

With each clock cycle, it is build something like this.

![[asynchronous-counter-2.png | center]]

The following model uses the `T_FF` module for the creation of a `4-bit` asynchronous counter.

```verilog
module asynchronous_up_counter
	(
		input clk,
		input reset,
		output [3:0] Q
	);
	
	T_FF FF0(
		.clk(clk),
		.T(1'b1),
		.reset(reset),
		.Q(Q[0])
	);
	
	T_FF FF1(
		.clk(~Q[0]),
		.T(1'b1),
		.reset(reset),
		.Q(Q[1])
	);
	
	T_FF FF2(
		.clk(~Q[1]),
		.T(1'b1),
		.reset(reset),
		.Q(Q[2])
	);
	
	T_FF FF3(
		.clk(~Q[2]),
		.T(1'b1),
		.reset(reset),
		.Q(Q[3])
	);

endmodule
```

This can be used with the following testbench.

```verilog
// Timescale
`timescale 1ns/1ps

// Module
module asynchronous_up_counter_tb;
	reg clk;
	reg reset;
	wire [3:0] Q;
	
	// Instantiate uut
	asynchronous_up_counter uut(
		.clk(clk),
		.reset(reset),
		.Q(Q)
	);
	
	// Timer
	initial
		#200 $stop;
	
	// Generate stimuli
	
	// Generate clk signal
	localparam T = 10; // clk period
	always
	begin
		clk = 1'b0;
		#(T/2);
		clk = 1'b1;
		#(T/2);
	end
	
	// Begin test
	initial begin
		// Issue a quick reset for 2 ns
		reset = 1'b0;
		#2 reset = 1'b1;
		$finish;
	end
	
	// Prints results to console
	initial begin
		$monitor("time=%0t reset=%b Q=%b", $time,
		reset, Q);
	end
	
	// Dumps .vcd file
	initial begin
		`ifdef VCD_PATH
		$dumpfile(`VCD_PATH);
		`else
		$dumpfile("default.vcd");
		`endif
		$dumpvars(0, asynchronous_up_counter_tb);
	end

endmodule
```

**Note**: *asynchronous counter cannot be used with fast circuits*.

# Synchronous Counter
A **synchronous counter** is built from flip-flops that all share the **same clock**. Every flip-flop updates at the same instant, and combinational logic in front of each one decides whether it toggles on that edge. This removes the accumulated ripple delay and the glitches of asynchronous counters.

![[synchronous-counter-1.png| center]]

Which basically is build like this.

![[synchronous-counter-2.png| center]]

The following model uses the `T_FF` module for the creation of a `4-bit` synchronous counter.

```verilog
module synchronous_up_counter
	(
		input clk,
		input reset,
		output [3:0] Q
	);
	
	wire Q0_next, Q1_next, Q2_next, Q3_next;
	
	assign Q0_next = 1'b1;
	T_FF FF0(
		.clk(clk),
		.T(Q0_next),
		.reset(reset),
		.Q(Q[0])
	);
	
	assign Q1_next = Q0_next & Q[0];
	T_FF FF1(
		.clk(clk),
		.T(Q1_next),
		.reset(reset),
		.Q(Q[1])
	);
	
	assign Q2_next = Q1_next & Q[1];
	T_FF FF2(
		.clk(clk),
		.T(Q2_next),
		.reset(reset),
		.Q(Q[2])
	);
	
	assign Q3_next = Q2_next & Q[2];
	T_FF FF3(
		.clk(clk),
		.T(Q3_next)),
		.reset(reset),
		.Q(Q[3])
	);

endmodule
```
**Note**: *`1'b1` can be an enable signal*.
