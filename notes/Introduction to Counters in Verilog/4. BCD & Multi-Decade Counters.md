# BCD Counter
A **BCD Counter** (Binary-Coded Decimal Counter), also known as a **decade counter**, is a digital circuit that counts sequentially from **0 to 9** using a `4-bit` binary output (**0000** to **1001**), automatically resetting to zero upon reaching the count of 9. The following module describes the **BCD Counter**.

```verilog
module BCD_counter
	(
		input clk,
		input reset_n,
		input enable,
		output done,
		output [3:0] Q
	);
	
	reg [3:0] Q_reg, Q_next;
	
	// Register
	always @(posedge clk, negedge reset_n)
	begin
		// Asynchronous reset
		if(~reset_n)
			Q_reg <= 0;
		// Enable counter
		else if(enable)
			Q_reg <= Q_next;
		// Counter disabled, maintain current value
		else
			Q_reg <= Q_reg;
	end
	
	// Next state logic
	assign done = Q_reg == 9;
	
	always @(*)
		Q_next = done? 'b0: Q_reg + 1;
	
	// Ouput logic
	assign Q = Q_reg;
	
endmodule
```

# Multi-Decade Counter
A **multidecade counter** is a digital circuit configuration created by **cascading** multiple individual decade counters to count beyond a single decimal digit (0–9).

![[multidecade-counter.png | center]]

The follwing module represents a **Multi-Decade Counter** cascating the `BCD_counter` module.

```verilog
module multi_decade_counter
	(
		input clk,
		input reset_n,
		input enable,
		output done, // to cascade it even more
		output [3:0] ones, tens, hundreds
	);
	
	wire done0, done1, done2;
	wire a0, a1, a2;
	
	BCD_counter D0(
		.clk(clk),
		.reset_n(reset_n),
		.enable(enable),
		.done(done0),
		.Q(ones)
	);
	assign a0 = enable & done0;
	
	BCD_counter D1(
		.clk(clk),
		.reset_n(reset_n),
		.enable(a0),
		.done(done1),
		.Q(tens)
	);
	assign a1 = a0 & done1;
	
	BCD_counter D2(
		.clk(clk),
		.reset_n(reset_n),
		.enable(a1),
		.done(done2),
		.Q(hundreds)
	);
	assign a2 = a1 & done2;
	
	assign done = a2;

endmodule
```

This module can be checked with the following testbench.

```verilog
// Timescale
`timescale 1ns/1ps

// Module
module multi_decade_counter_tb;
	reg clk;
	reg reset_n;
	reg enable;
	wire done;
	wire [3:0] ones;
	wire [3:0] tens;
	wire [3:0] hundreds;
	
	// Instantiate uut
	multi_decade_counter uut(
		.clk(clk),
		.reset_n(reset_n),
		.enable(enable),
		.done(done),
		.ones(ones),
		.tens(tens),
		.hundreds(hundreds)
	);
	
	// Generate clk signal
	localparam T = 5; // clk period
	always
	begin
		clk = 1'b0;
		#(T/2);
		clk = 1'b1;
		#(T/2);
	end
	
	// Begin test
	initial begin
		// Issue a quick reset for 2 ns
		reset_n = 1'b0;
		#2
		reset_n = 1'b1;
		#2
		enable = 1'b1;
		
		repeat(115) @(negedge clk);
		#20 $stop;
		
		$finish;
	end
	
	// Prints results to console
	initial begin
		$monitor("time=%0t reset_n=%b Q=%b", $time,
		reset_n, Q);
	end
	
	// Dumps .vcd file
	initial begin
		`ifdef VCD_PATH
		$dumpfile(`VCD_PATH);
		`else
		$dumpfile("default.vcd");
		`endif
		$dumpvars(0, multi_decade_counter_tb);
	end

endmodule
