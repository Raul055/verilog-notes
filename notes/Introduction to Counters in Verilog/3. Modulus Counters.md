# `N-Bits` Hardcoded Modulus Counter
The following module describe a `N-Bits` **Hardcoded Modulus Counter**.
```verilog
module hardcoded_modulus_counter
	#(parameter N=4)
	(
		input clk,
		input reset,
		input enable,
		output [N-1:0] Q
	);
	
	reg [N-1:0] Q_reg, Q_next;
	wire done;
	
	// Register
	always @(posedge clk, negedge reset)
	begin
		// Asynchronous reset
		if(reset)
			Q_reg <= 0;
		// Enable counter
		else if(enable)
			Q_reg <= Q_next;
		// Counter disabled, maintain current value
		else
			Q_reg <= Q_reg;
	end
	
	// Next state logic
	assign done = Q_reg == 7; // Hardcoded because of this
	
	always @(*)
		Q_next = done? 'b0: Q_reg + 1;
	
	// Ouput logic
	assign Q = Q_reg;
	
endmodule
```
	In this example, the counter counts UP until it reaches 7.

This module can be checked with the following testbench.

```verilog
// Timescale
`timescale 1ns/1ps

// Module
module hardcoded_modulus_counter_tb;
	localparam N=4;
	reg clk;
	reg reset;
	reg enable;
	wire [N-1:0] Q;
	
	// Instantiate uut
	hardcoded_modulus_counter #(.N(N)) uut(
		.clk(clk),
		.reset(reset),
		.enable(enable),
		.Q(Q)
	);
	
	// Timer
	initial
		#200 $stop;
	
	// Generate stimuli
	
	// Generate clk signal
	localparam T = 10; // clk period
	always
	begin
		clk = 1'b0;
		#(T/2);
		clk = 1'b1;
		#(T/2);
	end
	
	// Begin test
	initial begin
		// Issue a quick reset for 2 ns
		reset = 1'b0;
		#2
		reset = 1'b1;
		#2
		enable = 1'b1;
		$finish;
	end
	
	// Prints results to console
	initial begin
		$monitor("time=%0t reset=%b Q=%b", $time,
		reset, Q);
	end
	
	// Dumps .vcd file
	initial begin
		`ifdef VCD_PATH
		$dumpfile(`VCD_PATH);
		`else
		$dumpfile("default.vcd");
		`endif
		$dumpvars(0, hardcoded_modulus_counter_tb);
	end

endmodule
```

# `N-Bits` Parameter Modulus Counter
The following module describe a `N-Bits` **Parameter Modulus Counter**.
```verilog
module parameter_modulus_counter
	#(parameter FINAL_VALUE=9) // Final value is inclusive
	(
		input clk,
		input reset,
		input enable,
		output [N-1:0] Q
	);
	
	localparam N = $clog2(FINAL_VALUE);
	reg [N-1:0] Q_reg, Q_next;
	wire done;
	
	// Register
	always @(posedge clk, negedge reset)
	begin
		// Asynchronous reset
		if(reset)
			Q_reg <= 0;
		// Enable counter
		else if(enable)
			Q_reg <= Q_next;
		// Counter disabled, maintain current value
		else
			Q_reg <= Q_reg;
	end
	
	// Next state logic
	assign done = Q_reg == FINAL_VALUE; // Input
	
	always @(*)
		Q_next = done? 'b0: Q_reg + 1;
	
	// Ouput logic
	assign Q = Q_reg;
	
endmodule
```
	Here, the FINAL_VALUE represent the final value the counter will reach. The N-Bit is defined by $clog2
